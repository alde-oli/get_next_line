## ▸ Usage
Copy `get_next_line.c`, `get_next_line_utils.c` and `get_next_line.h` into your project and compile with a buffer size:
```bash
gcc -Wall -Wextra -Werror -D BUFFER_SIZE=42 get_next_line.c get_next_line_utils.c main.c
```
